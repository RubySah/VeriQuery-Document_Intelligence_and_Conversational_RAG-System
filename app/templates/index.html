Core capabilities

More than document storage.

A modular backend designed to transform unstructured documents into searchable knowledge and useful actions.

📄

Document Ingestion

Upload PDF and TXT documents, extract their content, and divide text into meaningful chunks using configurable chunking strategies.

🔎

Semantic Search

Generate vector embeddings and retrieve relevant document passages through similarity search powered by Qdrant.

🧠

Conversational RAG

Generate context-aware answers using retrieved document content and Google's Gemini models.

💬

Multi-turn Memory

Maintain conversation context across multiple questions using Redis-backed chat history and contextual query rewriting.

📅

Interview Booking

Extract candidate details, email, interview date, and time from conversations using AI-powered structured information extraction.

🛡️

Persistent Data

Store document metadata and booking records in PostgreSQL while maintaining vector data in a dedicated vector database.

How it works

From raw files to intelligent results.

A structured pipeline connecting document processing, vector retrieval, language models, and persistent memory.

01 / INGEST

Upload Documents

Extract text from PDF or TXT files and split content into manageable chunks.

02 / INDEX

Generate Embeddings

Convert text chunks into vector embeddings and store them in Qdrant.

03 / RETRIEVE

Ask Questions

Retrieve relevant passages and generate contextual responses using Gemini.

04 / ACT

Extract & Store

Extract interview information and save confirmed booking requests in PostgreSQL.
